# Dream League Soccer 2026 (brauzer versiyasi)

Three.js asosidagi 3D futbol o'yini. `index.html` faylini brauzerda oching, o'rnatish yoki server kerak emas.

## Boshqaruv

| Tugma | Hujumda | Himoyada |
|---|---|---|
| Joystik (chap tomon) | Yurish | Yurish |
| **A** | Pas (joystik yo'nalishidagi sherikka) | O'yinchini almashtirish |
| **B** | Zarba (qancha uzoq bossangiz, shuncha kuchli) | Sirpanib to'p olish |
| **C** | Sprint (stamina sarflaydi) | Sprint |

Kompyuterda: WASD yoki strelkalar bilan yuriladi, J = A, K = B, Shift = C, P = pauza.
